# OMDB Movie Search Project

A responsive single page movie search application built with HTML, CSS, and JavaScript using the OMDB API.

## Live Demo

https://aysenur-dogan.github.io/omdb-project/

---

## Project Overview

This project allows users to search for movies and view movie details dynamically.  
The application fetches movie information from the OMDB API and displays the movie title, year, genre, director, and poster.

The project was developed as part of the i2i Systems internship evaluation case.

---

## Technologies Used

- HTML
- CSS
- JavaScript
- OMDB API
- GitHub Pages

---

## Features

- Movie search by title
- Dynamic movie detail rendering
- Displaying title, year, genre, director, and poster
- Error handling for empty or invalid searches
- Responsive design for different screen sizes
- Multiple searches without refreshing the page
- Last searched movie is saved using LocalStorage
